# Booth Import Manager

BOOTH에서 산 에셋을 **클릭 한 번으로 원하는 유니티 프로젝트에 임포트**해 주는 도구입니다.
BOOTH 라이브러리나 주문 페이지에서 `프로젝트 → 태그 → ▶ Unity로` 순서로 고르면 다운로드, 압축 해제, 임포트, 폴더 정리까지 자동으로 진행됩니다.

> 크롬 확장과 유니티 패키지 두 개로 동작합니다. 따로 실행해 둘 프로그램은 없습니다.

## 무엇을 해주나요

- **원클릭 임포트**: BOOTH 라이브러리·주문 페이지의 파일마다 부스 Download 버튼 왼쪽에 `▶ Unity로` 버튼이 생깁니다.
- **여러 유니티 프로젝트**: ALCOM / VCC 프로젝트 폴더를 등록하면 그 안의 프로젝트를 자동으로 찾아 목록에 보여줍니다.
- **꺼져 있어도 예약**: 유니티가 꺼져 있는 프로젝트로 보내면 대기열에 넣어두고, 그 프로젝트를 켜는 순간 자동으로 임포트합니다.
- **태그 = 폴더**: 태그 이름대로 `Assets/<임포트 위치>/<태그>/` 아래에 정리됩니다. 프로젝트마다 쓸 태그를 따로 고를 수 있습니다.
- **폴더 아이콘 = 부스 썸네일**: 임포트한 폴더의 아이콘을 상품 썸네일로, 그 위 샵 폴더는 샵 프로필 사진으로 바꿔 보여줍니다.
- **어디에 넣었는지 기억**: 라이브러리 파일마다 `✓ MyAvatar +1` 같은 배지가 붙습니다. 마우스를 올리면 보낸 프로젝트 전체가 보입니다.
- **에셋 프리셋**: 자주 쓰는 에셋 묶음(받을 파일 + 저장 태그)을 기록해 두고, 새 프로젝트에 한 번에 밀어넣습니다.
- **찜목록 정리**: 이미 산 상품을 **풀팩 구매 / 일부 구매 / 구매**로 구분해서 찜 리스트로 분류하거나 찜에서 지웁니다.
- **부스 다크 테마**: 글자가 잘 읽히는 다크 모드.

## 구성

| 구성 | 하는 일 |
| --- | --- |
| **크롬 확장** | BOOTH 페이지에 버튼을 붙이고, 파일을 **다운로드 폴더 안의 대기열**에 바로 저장합니다. 태그·프로젝트 설정과 보낸 기록을 보관하고, 사이드패널·관리 페이지를 보여줍니다. |
| **유니티 패키지** | 각 유니티 프로젝트 안에서 자기 대기열을 지켜보다가 zip을 풀고, 패키지를 임포트하고, 태그 폴더로 정리합니다. 켜져 있는 동안 크롬 확장과 이야기하는 작은 연결(127.0.0.1:7840~7849)을 엽니다. |

```text
BOOTH 라이브러리 ──[▶ Unity로]──▶ 크롬 확장: 다운로드
                                   다운로드\BoothImportManager\대기열\<프로젝트>\<작업>\파일.zip + job.json
                                        │  (유니티가 꺼져 있으면 여기서 기다림)
                                        ▼
                         유니티 패키지: zip 해제 → 임포트 → Assets\<임포트 위치>\<태그>\ 로 정리
                                        → 원본은 보관 폴더로
```

## 설치

[Releases](../../releases)에서 최신 버전 파일을 받습니다.

| 파일 | 용도 |
| --- | --- |
| `BoothImportManager-ChromeExtension-v1.x.x.zip` | 크롬 확장 |
| `BoothImportManager-Unity-v1.x.x.unitypackage` | 유니티 패키지 (ALCOM/VCC를 쓰면 필요 없음) |
| `BoothThumbnailMatcher-Unity-v1.x.x.unitypackage` | (선택) 추가 도구: 이미 설치한 에셋에 썸네일 붙이기 — [썸네일 매칭](#썸네일-매칭-이미-설치한-에셋) |

### 1. 크롬 확장

1. zip을 풀어서 **지우지 않을 폴더**에 둡니다. (크롬은 이 폴더를 계속 읽습니다.)
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 1번 폴더 선택
5. 툴바의 퍼즐 아이콘에서 **Booth Import Manager**를 고정(📌)해 두면 편합니다.

### 2. 유니티 패키지 (프로젝트마다)

**ALCOM / VCC (추천)** — 저장소를 한 번 추가하면 프로젝트마다 패키지 목록에서 추가·업데이트할 수 있습니다.

1. ALCOM → 설정 → 패키지 → **저장소 추가** (VCC는 Settings → Packages → Add Repository)
2. 아래 주소 입력 (관리 페이지 → 프로젝트 탭의 **ALCOM에 추가** 버튼으로도 열 수 있습니다)

   ```text
   https://raw.githubusercontent.com/Luin48/Booth-Import-Manager/main/vpm/index.json
   ```

3. 프로젝트의 패키지 관리에서 **Booth Import Manager** 추가
4. (선택) 이미 설치해 둔 에셋에도 썸네일을 붙이려면 **BIM Thumbnail Matcher**도 추가

**직접 넣기** — `.unitypackage`를 유니티로 임포트하면 `Assets/BoothImportManager/`에 들어갑니다.

## 처음 설정

크롬 툴바의 확장 아이콘을 누르면 오른쪽에 **사이드패널**이 열립니다. 위쪽 **관리** 버튼을 눌러 관리 페이지를 엽니다.

1. 유니티 패키지를 설치한 프로젝트를 **하나 켭니다.** 관리 페이지 위쪽에 `유니티 1개 연결됨`이 보이면 정상입니다.
2. **프로젝트 탭 → 프로젝트 폴더**
   - ALCOM / VCC 프로젝트가 모여 있는 폴더를 추가합니다. (예: `C:\Users\<이름>\ALCOM\Projects`)
   - 자주 쓰는 위치는 **찾은 위치** 버튼으로 바로 추가할 수 있습니다. (`폴더 선택…`은 켜진 유니티가 창을 띄워 줍니다)
3. **프로젝트 탭 → 인식된 프로젝트**
   - **BIM 패키지** 칸에 설치된 버전이 보입니다. `미설치`면 ALCOM에서 추가하세요.
   - **임포트 위치**: 에셋이 들어갈 폴더입니다. (예: `Assets/BoothAssets`)
   - 안 쓰는 프로젝트는 **숨기기**, 표시 이름 칸에 별명을 넣을 수 있습니다.
4. **태그 탭**에서 태그를 정리합니다. 태그 이름이 유니티 안의 폴더 이름이 됩니다.
5. **프로젝트별 태그 탭**에서 프로젝트마다 쓸 태그를 체크합니다.
6. (선택) **설정 탭 → 보관 폴더**: 임포트가 끝난 원본 zip을 모아둘 곳. 비우면 `다운로드\BoothImportManager\보관`.

> 크롬 설정에서 **다운로드 전에 각 파일의 저장 위치 확인**은 꺼 두세요. 켜져 있으면 대기열 폴더가 아닌 곳에 저장될 수 있습니다.

## 사용법

### BOOTH 라이브러리에서 바로 임포트

[BOOTH 라이브러리](https://accounts.booth.pm/library)나 **주문 상세 페이지**(`accounts.booth.pm/orders/주문번호`)를 열면 상품마다 **BIM 바**가 붙습니다.

```text
【衣装】Sample Outfit …                         ← 상품 이름
[BIM] [▸ 파일 2개] ✓ MyAvatar +1   🟢[프로젝트▾] [태그▾]
   SampleOutfit_v1.zip           ⏳ MyAvatar [▶ Unity로] [Download] …
```

1. 상품 이름 아래 BIM 바에서 **프로젝트** 선택 — 드롭다운 왼쪽 동그라미가 🟢 유니티 실행 중 / 🔴 꺼짐. 몇 초마다 자동으로 갱신됩니다.
2. 같은 바에서 **태그** 선택 — 그 프로젝트에 할당한 태그만 보입니다.
3. 받을 파일 줄의 **▶ Unity로** — 위에서 고른 프로젝트·태그로 들어갑니다. 여러 에셋을 한 번에 넣으려면 [에셋 프리셋](#에셋-프리셋)을 쓰세요.

그다음은 자동입니다: 다운로드(대기열 폴더로) → 유니티가 zip 해제 → 임포트 → 태그 폴더로 정리 → 원본은 보관 폴더로.

편의 기능:

- **다운로드 항목 접기/펼치기**: 맨 위 BIM 줄의 **모두 펼치기 / 모두 접기**, 상품별 **▸ 파일 n개** 버튼. "처음에 접어두기"를 끄면 항상 펼친 상태로 시작합니다.
- **페이지당 상품 수**: 맨 위 BIM 줄에서 10 / 20 / 30 / 50개. 부스 다음 페이지들을 받아 이어 붙이고 페이지 번호도 맞춰 바뀝니다.
- **선택 따라가기**: 한 상품에서 고르면, 아직 직접 고르지 않은 다른 상품들도 같은 값으로 맞춰집니다.
- **기억**: 마지막 프로젝트와 프로젝트마다 마지막 태그를 기억합니다.
- **재다운로드 없음**: 이미 받아 보관 폴더에 있는 파일을 다른 프로젝트로 보내면, 켜진 유니티가 보관본을 복사해서 씁니다. (켜진 유니티가 없으면 새로 받습니다)
- **상태 배지**: 파일·상품마다 하나. BIM 바에서 고른 프로젝트 기준으로 `✓ 임포트됨`, `⏳ 받는 중·대기·임포트 중`, `⚠ 실패`를 보여주고, 다른 프로젝트에도 보냈으면 `+N`이 붙습니다. 배지에 마우스를 올리면 프로젝트별 상태와 태그 전체 목록이 나옵니다.

### 에셋 프리셋

새 프로젝트를 만들 때마다 같은 에셋들을 하나씩 넣는 대신, **받을 파일과 저장 태그만 묶어 두었다가 한 번에** 보냅니다.

**담기** (BOOTH 라이브러리·주문 페이지)

1. 맨 위 BIM 줄의 **에셋 프리셋**에서 프리셋을 고르거나 **＋ 새 프리셋…** 으로 만듭니다. (`담기 끔`이면 버튼이 안 보입니다)
2. 프리셋을 고르면 상품 BIM 바의 프로젝트 칸이 **📁 프리셋**으로 고정되고, 태그 칸에는 모든 태그가 나옵니다. 저장할 **태그**를 고릅니다. (프리셋 모드에서는 ▶ Unity로 버튼이 숨겨집니다. `담기 끔`으로 돌아가면 원래대로)
3. 파일 줄의 **＋ 프리셋**을 누르면 담깁니다. 상품의 파일을 다 담으려면 바의 **＋ 전부 프리셋**.
   - 담긴 파일은 `✓ 02.옷`처럼 저장 태그가 보입니다. 같은 태그로 다시 누르면 빠지고, 다른 태그를 고르고 누르면 태그가 바뀝니다.

**보내기**

- 관리 페이지 → **에셋 프리셋** 탭: 프리셋마다 **프로젝트 선택 → 한번에 보내기**. 항목별 태그 변경, 빼기, 프리셋 이름 바꾸기, 삭제도 여기서 합니다.
- 부스 사이드패널 → **프리셋** 탭: 위쪽 ① 에서 고른 프로젝트로 한번에 보내기.
- 이미 받아서 보관 폴더에 있는 파일은 다시 받지 않고 복사해서 씁니다. 유니티가 꺼져 있는 프로젝트로 보내면 대기열에 쌓였다가 켜면 임포트됩니다.

**업데이트 표시**

- 프리셋에 담은 상품에 새 버전 파일이 올라오거나 파일이 없어지면 **⚠ 다운로드 항목 바뀜**으로 표시하고 어떤 파일이 생기고 없어졌는지 보여줍니다.
- 라이브러리 페이지를 열 때마다 자동으로 확인하고, 관리 페이지의 **업데이트 확인**을 누르면 라이브러리 전체를 한 번에 확인합니다.
- **상품 페이지 ↗** 버튼으로 바로 그 상품의 BOOTH 페이지를 엽니다. 새 파일을 담은 뒤 **확인함**을 누르면 표시가 지워집니다.

### 부스 다크 테마

관리 페이지 → 설정 → **부스 테마: 라이트 / 다크** (사이드패널 위쪽 ☾ 버튼으로도 전환)

- 화면을 반전시키는 방식이 아니라, 부스가 쓰는 색을 하나씩 다크 팔레트로 다시 계산합니다. 배경은 푸른 기 없는 검정·회색 계열입니다. 사진·썸네일 색은 그대로이고, 빨간 장바구니 버튼 같은 브랜드 색도 유지됩니다.
- 글자와 배경의 대비가 부족한 곳은 따로 찾아서 읽기 좋게 고칩니다.
- 상점 페이지(`*.booth.pm`)까지 같이 적용됩니다. 처음 여는 페이지는 잠깐 밝게 보였다가 바뀔 수 있고, 다음부터는 바로 어둡게 열립니다.
- 버튼 글자색처럼 다른 색 변수를 거쳐 정해지는 색도 끝까지 따라가서 바꿉니다.
- 다른 다크 모드 확장과 같이 켜면 겹쳐서 이상하게 보일 수 있으니 하나만 쓰세요.

### 사이드패널

부스 페이지(`booth.pm`)에서 확장 아이콘을 누르면 열립니다. 다른 사이트에서는 사이드패널이 열리지 않고, 아이콘을 누르면 관리 페이지가 열립니다.

- **위쪽 ① 프로젝트 ② 태그**: 기록에서 다시 보낼 대상입니다.
- **보낸 기록 탭**: [Unity로]로 보낸 파일 목록과 프로젝트별 상태.
  - 필터: 최근 / 실패·패키지 없음 / 전체(숨김 포함)
  - 골라서 **③ 다시 보내기** — 다른 프로젝트·태그로 또 보낼 때
  - **숨김** / **기록 삭제** (파일은 그대로 둡니다)
- **대기열 탭**: 아직 임포트되지 않은 파일. 유니티가 꺼져 있어도 **취소**할 수 있습니다.
- **프리셋 탭**: 에셋 프리셋을 골라 ① 프로젝트로 한번에 보내기. 업데이트된 항목 표시와 상품 페이지 바로가기.
- **찜 정리 탭**: 아래 [찜목록 정리](#찜목록-정리) 참고

### 상품 페이지 패널

BOOTH 상품 페이지 오른쪽 아래에 작은 패널이 뜹니다. (산 적 없고 무료 파일도 없는 상품에서는 뜨지 않습니다)

- 구매 형태: **풀팩 구매 / 일부 구매 / 구매함**, 일부 구매면 산 옵션 이름
- 이 상품을 어느 프로젝트에 임포트했는지
- 무료 배포 파일이 있으면 바로 **▶ Unity로**
- `–` 버튼으로 접어둘 수 있고, 접은 상태가 기억됩니다.

### 찜목록 정리

이미 산 상품이 찜목록에 남아 있으면 구매 형태별로 정리합니다.

1. 사이드패널 → **찜 정리**
2. 구매 형태마다 할 일을 고릅니다.

   | 구매 형태 | 뜻 | 기본값 |
   | --- | --- | --- |
   | **풀팩 구매** | 풀세트/전체 옵션을 샀음 | `풀팩 구매` 리스트로 분류 |
   | **일부 구매** | 여러 옵션 중 일부만 샀음 (예: 내 아바타 대응판만) | `일부 구매` 리스트로 분류 |
   | **구매 (옵션 1개)** | 옵션이 하나뿐인 상품을 샀음 | `구매` 리스트로 분류 |

   할 일: **리스트로 분류**(리스트 이름은 바꿀 수 있음) / **찜 삭제** / **그대로**
3. **미리보기** — 라이브러리와 상품 정보를 읽어서 무엇이 바뀔지 보여줍니다. (상품 수에 따라 시간이 조금 걸립니다)
4. **실행** — 한 번 더 눌러야 확정됩니다.

리스트가 없으면 자동으로 만들어집니다. 상품이 원래 들어 있던 다른 찜 리스트는 그대로 둡니다.

**풀팩/일부 판별 기준** — BOOTH 상품 정보의 옵션별 구매 기록을 봅니다.

- 유료 옵션이 1개뿐 → **구매**
- 유료 옵션을 전부 샀음 → **풀팩 구매**
- 가장 비싼 '풀세트류' 옵션을 샀음 (이름에 Full / フル / セット / Set / Pack / 全部 / 풀 등) → **풀팩 구매**
- 옵션이 3개 이상이고, 혼자 제일 비싼 옵션을 샀음 → **풀팩 구매**
- 그 외 → **일부 구매**

### 관리 페이지

사이드패널의 **관리** 버튼, 또는 라이브러리 안내 배너에서 엽니다.

- **프로젝트**: 프로젝트 폴더 등록, 인식된 프로젝트 목록(실행 상태, 대기/실패 개수, 유니티 버전, BIM 패키지 버전), 임포트 위치, 숨기기, 별명, ALCOM 저장소 주소
- **태그**
  - 추가 (`모든 프로젝트에 추가` 체크 시 직접 선택 중인 프로젝트에도 바로 들어감)
  - 이름 바꾸기, 왼쪽 **⠿ 핸들**을 잡고 끌어서 순서 바꾸기 (핸들에 포커스를 두고 키보드 ↑ ↓도 됨)
  - 태그마다 **체크박스**: 체크한 태그로 태그 세트를 만들거나 갱신합니다. (맨 위 체크박스로 전체 선택/해제)
  - **복제**: 같은 프로젝트 할당까지 그대로 복사 (비슷한 태그를 하나 더 만들 때)
  - **삭제**: 두 번 눌러야 지워짐. 프로젝트 할당에서도 같이 빠집니다.
  - **태그 세트**: 자주 쓰는 태그 조합에 이름을 붙여 저장합니다. (예: `아바타 프로젝트용 공용 태그`, `월드 프로젝트용 태그`) 저장할 때 "체크한 태그", "현재 태그 전부", "특정 프로젝트의 태그" 중에서 고르고 **세트로 추가 / 갱신**을 누릅니다. (같은 이름이 있으면 덮어씀) 세트마다 **체크한 태그로 갱신**, **체크로 불러오기**(세트 내용을 체크박스로 옮김), **적용**(프로젝트 하나 또는 전체에 한 번에 적용) 버튼이 있습니다.
  - **태그 목록 복사/붙여넣기**: 현재 태그 구성을 텍스트로 복사해서 다른 PC나 친구에게 줄 수 있습니다. 붙여넣으면 이름이 같은 태그는 건너뛰고 새 것만 추가합니다. 한 줄에 태그 이름 하나씩 적어서 붙여넣어도 됩니다.
- **프로젝트별 태그**: 가로가 프로젝트, 세로가 태그인 표입니다.
  - **제한 없음**: 모든 태그를 씀 / **직접 선택**: 체크한 태그만 씀
  - **전체 / 해제**: 그 프로젝트의 태그를 한 번에 켜고 끔
  - **세트 적용…**: 저장해 둔 태그 세트를 그 프로젝트에 적용
  - **복사해오기…**: 다른 프로젝트의 태그 구성을 그대로 복사
  - 줄 끝의 **모두 켜기 / 모두 끄기**: 그 태그를 모든 프로젝트에서 켜고 끔
  - `태그 없음`은 항상 사용합니다. (임포트 위치 바로 아래에 넣고 싶을 때)
- **설정**: 다운로드·대기열·보관 폴더, 임포트 후 원본 보관/삭제, **부스 테마**, **크롬 확장 다시 불러오기**

### 유니티 폴더 아이콘

▶ Unity로 보낸 에셋은 임포트가 끝나면 프로젝트 창의 폴더 아이콘이 BOOTH 이미지로 바뀝니다.

```text
Assets/02.옷/
└─ SampleShop/          ← 샵 프로필 사진
   └─ SampleOutfit/     ← 상품 썸네일
```

- 대부분의 상품은 패키지 안이 `샵 이름/에셋 이름/...` 구조라서, 위쪽 폴더는 **샵 폴더**, 그 아래는 **에셋 폴더**로 봅니다.
  - 폴더 이름이 샵 이름이나 상품 이름과 비슷한지 비교합니다. (기호·공백 무시, 예: `Sample⚡Shop` ↔ `SampleShop`)
  - 맨 위 폴더가 상품 이름과 비슷하면 그 폴더 하나만 에셋 폴더로 봅니다.
  - 이름이 안 맞아도 맨 위 폴더 안에 폴더가 하나뿐이면 `샵/에셋` 구조로 봅니다.
- 이미지는 유니티가 임포트할 때 부스에서 직접 받아둡니다. (`%LOCALAPPDATA%\BoothImportManager\thumbs`)
- 폴더를 옮기거나 이름을 바꿔도 아이콘은 따라갑니다. 기록은 프로젝트의 `UserSettings/BoothImportManager`에 저장되고, 에셋 파일은 건드리지 않습니다.
- **이미 있는 폴더에 붙이기**: 프로젝트 창에서 폴더 우클릭 → `Booth Import Manager` → `부스 상품 연결 (썸네일 아이콘)…` → 상품 URL을 붙여넣고 **연결**. "상위 폴더 = 샵 폴더"를 켜두면 위 폴더에 샵 사진도 붙습니다.
- 우클릭 메뉴의 `부스 페이지 열기`로 그 상품 페이지를 바로 열 수 있고, `폴더 아이콘 지우기`로 원래 아이콘으로 돌릴 수 있습니다.
- 끄고 싶으면 `Tools > Booth Import Manager > Settings`의 **부스 썸네일 표시**를 끕니다.

### 썸네일 매칭 (이미 설치한 에셋)

BIM을 쓰기 전에 직접 넣어둔 에셋 폴더에도 BOOTH 썸네일을 한 번에 붙이는 **추가 도구**입니다. 따로 설치하는 유니티 패키지(**BIM Thumbnail Matcher**)이고, Booth Import Manager 유니티 패키지 1.0.3 이상이 필요합니다.

1. `Tools > Booth Import Manager > 썸네일 매칭 (설치된 에셋)` 창을 엽니다.
2. **① 부스 라이브러리 목록**: **부스에서 불러오기**를 누르면 크롬으로 BOOTH 라이브러리가 열리고, BIM 확장이 구매·선물 목록(상품 이름, 샵, 썸네일 주소, 파일 이름)을 `다운로드\BoothImportManager\_bim\library.json`에 저장합니다. 창이 자동으로 읽어요.
   - 크롬이 기본 브라우저가 아니면 BOOTH 라이브러리 페이지 맨 위 BIM 줄의 **🖼 썸네일 매칭용 목록 저장**(또는 관리 페이지 → 설정 → **라이브러리 목록 저장**)을 직접 누르세요.
3. **② 원본 파일로 정확히 찾기 (선택)**: 받아 둔 zip·unitypackage가 남아 있으면 그 안의 GUID를 프로젝트와 맞춰 봐서, 폴더를 옮기거나 이름을 바꿨어도 정확히 찾습니다.
   - 보관 폴더와 크롬 다운로드 폴더는 자동으로 보고, 다른 곳에 모아뒀다면 **폴더 추가…**
   - 처음 한 번은 파일을 읽느라 시간이 걸리지만 결과를 기억해 두어서 다음부터는 빠릅니다.
4. **③ 스캔해서 대조하기** → 결과가 탭으로 나옵니다.

| 탭 | 내용 |
| --- | --- |
| **자동 매칭** | 원본 파일로 확인됐거나 이름이 거의 같은 폴더. 기본으로 체크되어 있고, **다른 상품**으로 바꾸거나 **확인으로** 옮길 수 있습니다. |
| **확인 필요** | 애매한 폴더. 후보 카드(썸네일·이름·점수)를 눌러 고르거나 **직접 찾기…**로 라이브러리를 검색합니다. **샵 폴더** 토글로 샵 사진을 붙일 폴더인지 정합니다. |
| **못 찾음** | 맞는 상품을 못 찾은 폴더. **상품 찾기…**로 직접 고르거나, 여러 샵을 담은 폴더면 **분류 폴더로 보기**, 상관없는 폴더면 **숨기기**. |
| **이미 있음** | 이미 아이콘이 붙은 폴더. 잘못 붙었으면 **아이콘 지우기**. |

5. 아래 **선택한 N개에 썸네일 붙이기**를 누르면 부스에서 썸네일·샵 사진을 받아 붙입니다.

대조 방법:

- `01.헤어`, `02.옷`처럼 번호로 시작하는 분류 폴더는 건너뛰고 그 안을 봅니다.
- 샵 이름과 같은 폴더는 **샵 폴더**, 그 안에서는 그 샵의 상품 위주로 비교합니다. (`#SampleShop` ↔ `SampleShop`, `!SampleShop_Outfit` 같은 샵+상품 이름도 인식)
- 상품 이름·파일 이름과 비슷한 폴더는 **상품 폴더**이고, 그 안의 `Prefab`, `Materials` 같은 폴더는 더 보지 않습니다.
- 점수가 높고 2등과 차이가 클 때만 자동입니다. 깊숙한 폴더(아바타별 하위 폴더 등)나 다른 샵 폴더 안의 이름 일치는 자동으로 붙이지 않고 확인으로 보냅니다.
- 라이브러리에 없는 상품(무료 배포 등)은 **직접 찾기**에 상품 번호나 URL을 넣으면 됩니다.

## 유니티가 꺼져 있을 때

- 꺼져 있는 프로젝트로 보내도 크롬이 대기열 폴더에 파일과 `job.json`을 저장해 둡니다. 배지는 `대기`.
- 그 프로젝트를 켜면 유니티 패키지가 대기열을 확인하고 **오래된 것부터 차례로** 임포트합니다.
- 플레이 모드 중이거나 컴파일 중이면 끝날 때까지 기다립니다. 임포트 도중 스크립트가 다시 컴파일돼도 이어서 처리합니다.
- 실패한 파일은 보관 폴더로 옮겨지고 배지가 `실패`로 바뀝니다. 사이드패널에서 다시 보낼 수 있습니다.
- 실행 상태(🟢/🔴)는 켜진 유니티가 직접 응답하는지로 판단합니다.

## 폴더 구조

```text
크롬 다운로드 폴더 (예: C:\Users\<이름>\Downloads)
└─ BoothImportManager\
   ├─ 대기열\
   │  └─ <프로젝트키>\<작업>\파일.zip + job.json   ← 임포트 기다리는 중
   ├─ 보관\                                      ← 임포트 끝난 원본 (설정에서 위치 변경)
   └─ _bim\done\                                 ← 처리 결과 (배지 표시에 사용)

%LOCALAPPDATA%\BoothImportManager\
├─ bim.json      ← 대기열·보관 폴더 위치 (크롬 확장이 정해 줌, 모든 프로젝트 공용)
└─ thumbs\       ← 폴더 아이콘용 썸네일

유니티 프로젝트
└─ Assets\<임포트 위치>\<태그>\<상품 폴더>\...
```

`프로젝트키`는 프로젝트 경로로 만든 짧은 해시 + 폴더 이름입니다. (예: `1a2b3c4d_MyAvatar`)

## 자주 묻는 질문 / 문제 해결

**관리 페이지에 "켜진 유니티가 없어요"라고 나와요**
유니티 패키지가 설치된 프로젝트를 하나 켜세요. 태그 정리, [Unity로] 예약은 유니티가 꺼져 있어도 됩니다. 프로젝트 목록 갱신과 폴더 선택 창만 켜진 유니티가 필요합니다.

**계속 🔴 꺼짐으로 나와요**
그 프로젝트에 v1.0 유니티 패키지가 들어 있는지 확인하세요. `Tools > Booth Import Manager > Settings`에서 **크롬 확장 연결: 켜짐 (127.0.0.1:78xx)** 이 보이면 정상입니다. 유니티를 11개 이상 동시에 켜면 포트(7840~7849)가 모자랍니다.

**파일이 대기열 폴더가 아닌 곳에 저장됐다고 나와요**
크롬 설정의 **다운로드 전에 각 파일의 저장 위치 확인**을 끄세요. 다운로드 위치를 바꾸는 다른 확장이 있다면 같이 쓰지 마세요.

**대기에서 넘어가지 않아요**
- 유니티 창을 한 번 클릭해 보세요. 유니티는 창이 뒤에 있을 때 일부 처리를 미룹니다.
- 플레이 모드를 끝내면 임포트가 시작됩니다.
- 콘솔에 `[BoothImportManager]` 로그가 있는지 확인하세요.

**압축 파일 안에 unitypackage가 없어요 (`패키지 없음`)**
텍스처나 PSD만 들어 있는 상품입니다. 보관 폴더의 원본 zip을 직접 쓰면 됩니다.

**암호가 걸린 zip이라고 나와요**
상품 설명에 있는 비밀번호로 직접 풀어서 `.unitypackage`를 임포트해 주세요.

**찜 정리 미리보기가 안 돼요**
BOOTH에 로그인되어 있어야 합니다. 정리 중에는 BOOTH 탭이 잠깐 열렸다 닫힐 수 있습니다.

**유니티에 컴파일 에러가 나요 (같은 클래스가 두 번 정의됨)**
`Assets/BoothImportManager`와 `Packages/local.booth-import-manager` 두 곳에 다 들어간 경우입니다. `Assets` 쪽을 지워 주세요.

## 알아둘 점

- BOOTH(pixiv)의 공식 도구가 아닙니다. BOOTH 화면 구조가 바뀌면 버튼이 안 붙거나 찜 정리가 실패할 수 있습니다.
- 찜 정리는 BOOTH 웹사이트가 쓰는 기능을 내 로그인 상태로 그대로 호출합니다. 처음에는 몇 개만 정리해 보고 결과를 확인하는 것을 추천합니다.
- 받은 에셋의 이용 약관은 각 상품의 약관을 따릅니다. 이 도구는 파일을 옮기고 임포트만 합니다.
- 이미 유니티 프로젝트에 들어 있는 에셋 폴더를 다시 분류할 때는 [Unity Asset Classifier](https://github.com/Luin48/Unity-Asset-Classifier)를 추천합니다.
