## Booth Import Manager v1.0.2

v1.0.0 이후의 기능을 정식으로 반영한 버전입니다.

### 새 기능: 에셋 프리셋

자주 쓰는 에셋 묶음(받을 파일 + 저장 태그)을 기록해 두었다가, 새 프로젝트에 한 번에 밀어넣습니다.

- **담기**: BOOTH 라이브러리·주문 페이지 맨 위 BIM 줄의 **에셋 프리셋**에서 프리셋을 고르거나 새로 만들기
  - 프리셋 모드에서는 상품 BIM 바의 프로젝트 칸이 **📁 프리셋**으로 고정되고, 태그는 전부 보입니다
  - 파일마다 **＋ 프리셋**, 상품마다 **＋ 전부 프리셋** (▶ Unity로 버튼은 숨겨짐)
- **보내기**: 관리 페이지 **에셋 프리셋** 탭 또는 부스 사이드패널 **프리셋** 탭에서 프로젝트를 골라 한번에 보내기
  - 이미 받은 파일은 보관본을 복사, 꺼진 프로젝트로 보내면 켤 때 임포트
- **업데이트 표시**: 담은 상품에 새 파일이 올라오거나 파일이 없어지면 **⚠ 다운로드 항목 바뀜** 표시, **상품 페이지 ↗** 바로가기, **확인함**으로 표시 지우기
  - 라이브러리를 열 때 자동 확인, 관리 페이지 **업데이트 확인**으로 전체 확인

### 바뀐 점

- **상태 배지를 하나로**: 여러 프로젝트로 임포트해도 파일·상품마다 배지가 하나만 표시됩니다
  - 상품 BIM 바에서 고른 프로젝트 기준으로 `✓ 프로젝트명`, 다른 프로젝트는 `+N`으로 개수만
  - 배지에 마우스를 올리면 보낸 프로젝트 전체(상태·태그) 목록
  - 프로젝트를 바꾸면 배지도 바로 그 프로젝트 기준으로 바뀜
  - 대기 중·실패한 기록이 있으면 그것을 먼저 표시, 취소한 기록은 배지에서 제외
  - 상품 페이지 패널은 지금처럼 프로젝트별로 전부 표시
- **'전부 Unity로' 버튼 제거**: 파일마다 있는 ▶ Unity로 버튼을 쓰세요 (여러 개를 한 번에 보내려면 에셋 프리셋)

### 설치·업데이트

- **크롬 확장**: 아래 zip을 풀어 기존 폴더에 덮어쓰고 `chrome://extensions`에서 ↻ (크롬 웹스토어 버전은 스토어 업데이트로 반영)
- **유니티 패키지**: ALCOM/VCC에서 Booth Import Manager를 1.0.2로 업데이트, 또는 아래 unitypackage 임포트
