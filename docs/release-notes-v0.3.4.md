## Booth Import Manager v0.3.4

v0.3.3은 따로 배포하지 않고 이번 버전에 합쳤습니다.

### 바뀐 것

- **부스 다크 테마 (새로 만듦)** — 부스 사이트 전체를 다크로 보여줍니다.
  - 배경은 푸른 기 없는 검정·회색 계열
  - 화면을 반전시키지 않고 부스 CSS의 색을 하나씩 다크 팔레트로 다시 계산 → 사진 색 그대로, 빨간 장바구니 같은 브랜드 색 유지
  - 글자/배경 대비가 부족한 곳은 자동으로 보정해서 글자가 잘 읽힙니다
  - 설정: 관리 페이지 → 설정 → **부스 테마: 라이트 / 다크** (사이드패널 ☾ 버튼으로도 전환). v0.3.2의 '자동/켜기/끄기'는 없어졌습니다
- **라이브러리 / 주문 상세 화면 정리**
  - 프로젝트·태그 지정은 **상품 이름 아래 BIM 바에 하나만**
  - 파일 줄에는 부스 **Download 버튼 왼쪽에 [▶ Unity로] 버튼만** — 위에서 고른 프로젝트·태그로 임포트
  - 아직 직접 고르지 않은 다른 상품은 처음 고른 값을 따라감
- **다운로드 항목 접기/펼치기** — 라이브러리 맨 위 *모두 펼치기 / 모두 접기*, 상품별 *▸ 파일 n개* 버튼. 라이브러리는 기본으로 접힌 상태 ("처음에 접어두기"로 변경 가능)
- **페이지당 상품 수 10 / 20 / 30 / 50** — 라이브러리 맨 위 BIM 줄에서 선택. 부스 다음 페이지들을 받아 이어 붙이고 페이지 번호도 맞춰 바뀝니다
- **프로젝트 실행 상태 아이콘** — 드롭다운엔 이름만, 왼쪽 동그라미가 🟢 실행 중 / 🔴 꺼짐. 몇 초마다 실시간 갱신
- **라이브러리 BIM 바 빨리 뜨게** — 프로젝트 목록을 캐시해서 먼저 그리고, 로컬 앱 조회도 가벼워졌습니다 (프로젝트 폴더 전체 검색 제거)
- **태그 관리**
  - 태그 라이브러리에 체크박스 → 체크한 태그로 태그 세트 **추가 / 갱신**, 세트 내용을 **체크로 불러오기**
  - 태그 색 지정 제거
- **유니티 패키지 설치/업데이트 버튼 수정** — `Assets` 안 예전 복사본은 지우고 `Packages`로 옮겨 설치, 설치된 버전과 최신 버전 표시
- **로컬 앱 실행 시 페이지를 열지 않음** — 트레이에만 상주. 예전 웹 화면은 더 이상 열리지 않습니다

### 받을 파일

| 파일 | 용도 |
| --- | --- |
| `BoothImportManager-v0.3.4.exe` | 로컬 앱 (트레이 아이콘) |
| `BoothImportManager-ChromeExtension-v0.3.4.zip` | 크롬 확장 |
| `BoothImportManager-Unity-v0.3.4.unitypackage` | 유니티 패키지 (v0.3.1과 같음) |

### 업데이트 방법

1. 트레이 → 종료 후 새 exe로 교체 (`config.json`은 그대로)
2. 크롬 확장 폴더에 새 zip을 덮어쓰고, 관리 페이지 → 설정 → *크롬 확장 다시 불러오기* (또는 `chrome://extensions`에서 ↻)
3. 관리 페이지 → 프로젝트에서 `Assets 안 (예전 방식)` 프로젝트는 **업데이트**를 눌러 Packages로 옮기기
4. 다른 다크 모드 확장을 쓰고 있었다면 꺼 주세요
