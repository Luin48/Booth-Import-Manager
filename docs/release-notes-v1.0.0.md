## Booth Import Manager v1.0.0

첫 정식 버전입니다. (v0.4.0은 따로 배포하지 않고 이번 버전에 합쳤습니다)

**이제 exe가 없습니다.** 크롬 확장과 유니티 패키지 두 개만으로 동작합니다.

### 어떻게 바뀌었나

- [Unity로]를 누르면 크롬이 파일을 `다운로드\BoothImportManager\대기열\<프로젝트>\` 에 바로 저장하고, 태그·상품 정보를 `job.json`으로 옆에 남깁니다.
- 유니티 패키지가 그 대기열을 보고 **zip 해제(일본어 파일 이름 포함) → 임포트 → 태그 폴더 정리 → 원본은 보관 폴더로**까지 직접 합니다.
- 유니티가 꺼져 있으면 파일이 대기열에서 기다리다가, 그 프로젝트를 켜면 임포트됩니다.
- 켜진 유니티는 `127.0.0.1:7840~7849`에서 크롬 확장과 연결됩니다. 실행 상태(🟢/🔴), 프로젝트 목록, 폴더 선택 창을 여기서 처리합니다.
- 태그, 태그 세트, 프로젝트별 설정, 보낸 기록은 크롬 확장에 저장됩니다.
- 부스의 원래 Download 버튼은 건드리지 않습니다. 평소처럼 크롬 다운로드 폴더에 받아집니다.

### 새 기능

- **ALCOM / VCC 저장소**: `https://raw.githubusercontent.com/Luin48/Booth-Import-Manager/main/vpm/index.json` 을 저장소로 추가하면 프로젝트마다 패키지를 추가·업데이트할 수 있습니다. (관리 페이지 → 프로젝트 탭의 **ALCOM에 추가** 버튼)
- **사이드패널은 부스 페이지에서만** 열립니다. 다른 사이트에서 아이콘을 누르면 관리 페이지가 열립니다.
- **태그 순서**: ⠿ 핸들을 잡고 끌어서 바꿉니다. (키보드 ↑ ↓도 가능)
- 관리 페이지 프로젝트 목록에는 BIM 패키지 **버전만** 표시합니다. 설치·업데이트는 ALCOM에서 합니다.
- 사이드패널 **보낸 기록**: 보낸 파일과 프로젝트별 상태, 다른 프로젝트로 다시 보내기. 대기열은 유니티가 꺼져 있어도 취소할 수 있습니다.

### 고친 것

- 부스 다크 테마: 주문 페이지의 Download / Other Downloads 버튼 글씨가 안 보이던 문제 (다른 색 변수를 거쳐 정해지는 색을 끝까지 따라가서 변환)
- 상품 페이지 패널의 무료 파일 [Unity로] 버튼이 안 보이던 문제

### v0.3에서 업데이트

1. 크롬 확장 폴더에 새 zip을 덮어쓰고 `chrome://extensions`에서 ↻
2. 각 프로젝트의 `Assets/BoothImportManager`(예전 복사본)를 지우고 ALCOM에서 **Booth Import Manager** 추가
3. exe 종료, 시작 프로그램 등록 해제
4. 크롬 설정의 "다운로드 전에 각 파일의 저장 위치 확인"은 꺼 두세요
