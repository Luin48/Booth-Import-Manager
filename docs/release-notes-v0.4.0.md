## Booth Import Manager v0.4.0

**이제 exe가 없습니다.** 크롬 확장과 유니티 패키지 두 개만으로 동작합니다.

### 어떻게 바뀌었나

- [Unity로]를 누르면 크롬이 파일을 `다운로드\BoothImportManager\대기열\<프로젝트>\` 에 바로 저장하고, 태그·상품 정보를 `job.json`으로 옆에 남깁니다.
- 유니티 패키지가 그 대기열을 보고 **zip 해제(일본어 파일 이름 포함) → 임포트 → 태그 폴더 정리 → 원본은 보관 폴더로**까지 직접 합니다.
- 유니티가 꺼져 있으면 파일이 대기열에서 기다리다가, 그 프로젝트를 켜면 임포트됩니다.
- 켜진 유니티는 `127.0.0.1:7840~7849`에서 크롬 확장과 연결됩니다. 실행 상태(🟢/🔴), 프로젝트 목록, 다른 프로젝트에 패키지 설치, 폴더 선택 창을 여기서 처리합니다.
- 태그, 태그 세트, 프로젝트별 설정, 보낸 기록은 크롬 확장에 저장됩니다.

### 새 기능

- **프로젝트 없음 (다운로드 폴더로)**: 프로젝트 목록 맨 아래. 고르면 버튼이 **⬇ 받기**로 바뀌고 원래 다운로드 폴더에 그대로 받습니다.
- **ALCOM / VCC 저장소**: 관리 페이지 → 설정 → **ALCOM에 추가**로 패키지 저장소를 등록하면 프로젝트마다 패키지를 추가·업데이트할 수 있습니다.
- **v0.3 설정 자동 가져오기**: v0.3 exe가 켜진 상태에서 확장을 업데이트하면 태그·세트·프로젝트 설정·보관 폴더를 가져옵니다.
- 사이드패널 **보낸 기록**: 보낸 파일과 프로젝트별 상태, 다른 프로젝트로 다시 보내기. 대기열은 유니티가 꺼져 있어도 취소할 수 있습니다.

### 고친 것

- 부스 다크 테마: 주문 페이지의 Download / Other Downloads 버튼 글씨가 안 보이던 문제 (다른 색 변수를 거쳐 정해지는 색을 끝까지 따라가서 변환)
- 상품 페이지 패널의 무료 파일 [Unity로] 버튼이 안 보이던 문제

### 받을 파일

| `BoothImportManager-ChromeExtension-v0.4.0.zip` | 크롬 확장 |

| `local.booth-import-manager-0.4.0.zip` | ALCOM/VCC 저장소용 (직접 받을 필요 없음) |

### v0.3에서 업데이트

1. **v0.3 exe를 켜 둔 채로** 크롬 확장 폴더에 새 zip을 덮어쓰고 `chrome://extensions`에서 ↻ → 설정 자동으로 가져옴
2. 첫 프로젝트에 새 유니티 패키지 설치 (Assets 안 예전 `BoothImportManager` 폴더는 먼저 지우기) → 그 유니티를 켠 채로 관리 페이지 → 프로젝트 탭에서 나머지 프로젝트 **업데이트**
3. exe 종료, 시작 프로그램 등록 해제
4. 크롬 설정의 "다운로드 전에 각 파일의 저장 위치 확인"은 꺼 두세요
