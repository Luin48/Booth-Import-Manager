## Booth Import Manager v0.3.1

v0.3.0 위에 기능을 더한 업데이트입니다. 처음 설치하는 분은 [README](https://github.com/Luin48/Booth-Import-Manager#readme)의 설치 순서를 따라 주세요. (v0.2와는 사실상 다른 프로그램이라, 예전 "Booth Import Manager Bridge" 확장은 지워야 합니다)

### 받을 파일

| 파일 | 용도 |
| --- | --- |
| `BoothImportManager-v0.3.1.exe` | 로컬 앱 |
| `BoothImportManager-ChromeExtension-v0.3.1.zip` | 크롬 확장 |
| `BoothImportManager-Unity-v0.3.1.unitypackage` | 유니티 패키지 (선택 — 관리 페이지의 설치/업데이트 버튼 권장) |

### 새로 생긴 것

- **유니티 폴더 아이콘 = 부스 썸네일**
  - 임포트한 에셋 폴더는 상품 썸네일, 그 위 샵 폴더는 샵 프로필 사진으로 표시
  - `샵 이름/에셋 이름` 구조를 이름 비교로 찾아냄 (기호·공백 무시)
  - 폴더를 옮기거나 이름을 바꿔도 유지, 에셋 파일은 건드리지 않음 (`UserSettings`에 기록)
  - 예전에 넣은 폴더도 우클릭 → `Booth Import Manager → 부스 상품 연결`로 붙이기
  - 우클릭 → `부스 페이지 열기`
- **주문 상세 페이지 지원** — `accounts.booth.pm/orders/…` 에서도 파일마다 `[프로젝트][태그][▶ Unity로]`
- **태그 세트** — 태그 조합에 이름을 붙여 저장하고 프로젝트에 한 번에 적용 (관리 페이지 → 태그, 프로젝트별 태그 표의 `세트 적용…`)

### 고친 것

- 큐에 넣는 중간에 유니티가 덜 복사된 패키지를 집어 가지 않도록, 다 복사한 뒤 이름을 바꿔 넣음
- 패키지 안 경로를 읽을 때 유니티 버전에 따라 붙는 추가 줄을 무시

### 업데이트 방법

1. 로컬 앱: 관리 페이지 → 설정 → **로컬 앱 종료** 후 새 exe로 교체 (`config.json`은 그대로)
2. 크롬 확장: 새 zip을 같은 폴더에 덮어쓰고 `chrome://extensions`에서 새로고침(↻)
3. 유니티: 관리 페이지 → 프로젝트 → **재설치 / v0.3로 업데이트**
