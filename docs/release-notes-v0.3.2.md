## Booth Import Manager v0.3.2

### 새로 생긴 것

- **트레이 아이콘** — 로컬 앱이 작업 표시줄 트레이에 상주합니다. (그동안은 창 없이 돌아서 실행 중인지 알기 어려웠습니다)
  - 더블클릭 / **관리 페이지 열기** — 크롬 확장의 관리 페이지를 바로 엽니다
  - **보관 폴더 열기**, **예전 웹 화면 열기**
  - **윈도우 시작 시 자동 실행** 체크 (로그인 때 트레이로 조용히 시작)
  - **종료**
- **부스 페이지 다크 모드** — 부스 화면에 붙는 버튼·선택칸·배지·상품 패널이 다크 테마를 지원합니다.
  - 관리 페이지 → 설정 → *부스 페이지 표시*: `자동`(부스 화면이 어두우면 다크) / `켜기` / `끄기`
  - 바꾸면 열려 있는 부스 탭에도 바로 적용됩니다.
- 관리 페이지 → 설정 → **크롬 확장 다시 불러오기** 버튼 (확장 폴더를 새 버전으로 바꾼 뒤 누르면 됨)

### 받을 파일

| 파일 | 용도 |
| --- | --- |
| `BoothImportManager-v0.3.2.exe` | 로컬 앱 |
| `BoothImportManager-ChromeExtension-v0.3.2.zip` | 크롬 확장 |
| `BoothImportManager-Unity-v0.3.2.unitypackage` | 유니티 패키지 (v0.3.1과 같음) |

### 업데이트 방법

1. 트레이 또는 관리 페이지에서 로컬 앱 종료 → 새 exe로 교체 (`config.json`은 그대로)
2. 크롬 확장 폴더에 새 zip을 덮어쓰고 `chrome://extensions`에서 새로고침(↻) — v0.3.2부터는 관리 페이지의 *크롬 확장 다시 불러오기*로도 됩니다
