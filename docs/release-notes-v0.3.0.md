## Booth Import Manager v0.3.0

> ⚠️ **v0.2와 사실상 다른 프로그램입니다.** 이름과 저장소만 이어받았고 크롬 확장·로컬 앱·유니티 패키지 대부분을 새로 만들었습니다. 세 가지 모두 v0.3끼리 맞춰 써야 하고, **예전 "Booth Import Manager Bridge" 크롬 확장은 꼭 지워 주세요.**

### 받을 파일

| 파일 | 용도 |
| --- | --- |
| `BoothImportManager-v0.3.0.exe` | 로컬 앱 (전용 폴더에 두고 실행) |
| `BoothImportManager-ChromeExtension-v0.3.0.zip` | 크롬 확장 (압축 풀고 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드) |
| `BoothImportManager-Unity-v0.3.0.unitypackage` | 유니티 패키지 (선택 — 관리 페이지의 **설치** 버튼으로도 넣을 수 있음) |

자세한 설치·사용법은 [README](https://github.com/Luin48/Booth-Import-Manager#readme)에 있습니다.

### 새로 생긴 것

- **BOOTH 라이브러리 원클릭 임포트** — 파일마다 `[프로젝트▾][태그▾][▶ Unity로]`, 상품마다 `전부 Unity로`
- **여러 유니티 프로젝트** — ALCOM/VCC 프로젝트 폴더를 등록하면 자동 인식, 프로젝트마다 별도 대기열
- **꺼져 있어도 예약** — 유니티가 꺼진 프로젝트로 보내면 대기했다가 켜는 순간 자동 임포트, `● 실행 중 / ○ 꺼짐` 표시
- **관리 페이지** — 태그 라이브러리(추가·복제·순서·색), 프로젝트별 태그 표, 다른 프로젝트 태그 복사, 태그 세트 복사/붙여넣기, 프로젝트별 임포트 위치, 유니티 패키지 원클릭 설치
- **사이드패널** — 받은 파일 보내기, 프로젝트별 대기열(취소·재시도)
- **상태 배지** — 라이브러리와 상품 페이지에 `MyAvatar · 임포트됨`처럼 어디에 넣었는지 표시
- **찜목록 정리** — 산 상품을 풀팩 구매 / 일부 구매 / 구매로 판별해서 찜 리스트로 분류하거나 삭제 (미리보기 후 실행)
- **편의 기능** — 마지막 선택 기억, 같은 페이지 선택 따라가기, 이미 받은 파일 재다운로드 없이 다른 프로젝트로, 일본어 파일명 zip 해제

### 바뀐 것 / 고친 것

- 웹 화면 탭을 닫아도 로컬 앱이 꺼지지 않음 (`--background` 실행 옵션 추가)
- **보안**: 로컬 앱이 크롬 확장과 자기 화면의 요청만 받도록 변경 (v0.2는 아무 웹사이트에서나 로컬 삭제 API 호출 가능)
- 유니티 대기열 기록이 프로젝트끼리 섞이던 문제 수정
- 임포트 실패한 패키지를 무한 재시도하던 문제 수정 (`.failed`로 표시 후 재시도 가능)
- 같은 zip을 보낼 때마다 새로 풀던 것을 재사용하도록 변경
- 크롬 다운로드 위치가 설정과 달라도 실제 받은 위치에서 파일을 찾음

### v0.2에서 옮겨오기

1. 예전 크롬 확장 삭제 → 새 확장 설치
2. 예전 `config.json`을 새 exe 옆에 두면 폴더·태그 설정 유지
3. 관리 페이지 → 프로젝트 → `Assets 안 (이전 방식)`으로 보이는 프로젝트는 **v0.3로 업데이트** 버튼 (unitypackage로 덮어쓰면 스크립트가 두 벌이 될 수 있으니 기존 `Assets/BoothImportManager` 폴더를 먼저 지우고 임포트)

### 알려진 제한

- BOOTH 비공식 도구라 BOOTH 화면이 바뀌면 일부 기능이 멈출 수 있습니다.
- 찜 정리는 처음에 몇 개만 시험해 보는 것을 추천합니다.
- 서명하지 않은 exe라 SmartScreen 경고가 뜰 수 있습니다 (`추가 정보 → 실행`).
