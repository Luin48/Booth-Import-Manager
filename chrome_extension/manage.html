프로젝트 폴더

ALCOM / VCC 프로젝트들이 모여 있는 폴더를 등록하면 안의 유니티 프로젝트를 자동으로 찾아요.

폴더 밖에 있는 프로젝트 하나만 추가

인식된 프로젝트

프로젝트 상태 유니티 패키지 임포트 위치 (Asset root) 목록

유니티 패키지가 설치된 프로젝트는, 꺼져 있을 때 보낸 임포트도 다음에 켜면 자동으로 처리해요.

태그 라이브러리

태그 이름이 유니티 안의 폴더 이름이 돼요 (Asset root/태그/…). "태그 없음"은 Asset root 바로 아래로 들어가요.

태그 세트

자주 쓰는 태그 조합에 이름을 붙여 저장해 두고, 프로젝트에 한 번에 적용해요. (예: 아바타 프로젝트용 / 월드 프로젝트용)

태그 목록 복사 / 붙여넣기

다른 PC나 친구와 태그 구성을 공유할 때 써요. 붙여넣으면 이름이 같은 태그는 건너뛰고 새 것만 추가돼요.

프로젝트별 태그

체크한 태그만 그 프로젝트의 태그 목록에 보여요. "제한 없음"이면 전체 태그를 다 써요.
