Booth Import Manager

확인 중…
켜진 유니티가 없어요. 태그 정리는 그대로 할 수 있어요. 프로젝트 목록 갱신·패키지 설치·폴더 선택은 BIM 패키지가 설치된 유니티 프로젝트를 하나 켜면 돼요.

프로젝트 폴더

ALCOM / VCC 프로젝트들이 모여 있는 폴더를 등록하면 안의 유니티 프로젝트를 자동으로 찾아요.

폴더 밖에 있는 프로젝트 하나만 추가

인식된 프로젝트

프로젝트 상태 BIM 패키지 임포트 위치 (Asset root) 목록

유니티 패키지가 설치된 프로젝트는, 꺼져 있을 때 보낸 임포트도 다음에 켜면 자동으로 처리해요.

유니티 패키지 (ALCOM / VCC)

ALCOM(또는 VCC)에 아래 저장소를 한 번 추가하면, 프로젝트마다 패키지 목록에서 Booth Import Manager를 추가하고 업데이트할 수 있어요.

태그 라이브러리

태그 이름이 유니티 안의 폴더 이름이 돼요 (Asset root/태그/…). "태그 없음"은 Asset root 바로 아래로 들어가요.

태그 세트

자주 쓰는 태그 조합에 이름을 붙여 저장해 두고, 프로젝트에 한 번에 적용해요. (예: 아바타 프로젝트용 / 월드 프로젝트용)

태그 목록 복사 / 붙여넣기

다른 PC나 친구와 태그 구성을 공유할 때 써요. 붙여넣으면 이름이 같은 태그는 건너뛰고 새 것만 추가돼요.

프로젝트별 태그

체크한 태그만 그 프로젝트의 태그 목록에 보여요. "제한 없음"이면 전체 태그를 다 써요.

에셋 프리셋

BOOTH 라이브러리 맨 위 BIM 줄에서 "에셋 프리셋"을 고르면 파일마다 ＋ 프리셋 버튼이 생겨요. 받을 파일과 저장 태그만 모아 두었다가, 여기서 프로젝트를 골라 한 번에 보내요.

폴더

v0.4부터는 따로 실행하는 프로그램(exe)이 없어요. [Unity로]를 누르면 크롬이 아래 대기열 폴더에 바로 저장하고, 유니티가 거기서 가져가 임포트해요.

부스 테마

썸네일 매칭 (Unity)

이미 설치해 둔 에셋 폴더에도 부스 썸네일을 붙이는 유니티 'BIM 썸네일 매칭' 창에서 쓸 BOOTH 라이브러리 목록을 저장해요. 유니티 창의 [부스에서 불러오기]를 눌러도 같아요.
